# Purpose

## Why this repository exists

This repository publicly shares a curated selection of Brian Murdock's Codex
skills. It gives other Codex users a place to discover, inspect, and reuse the
skills Brian chooses to publish.

## Goals

- Publish selected skills deliberately, with a clear purpose for each inclusion.
- Provide enough context for readers to understand when and how to use each skill.
- Prepare published skills for use outside Brian's personal environment by making
  prerequisites and assumptions explicit.
- Keep private information, credentials, and unpublished material out of public
  skill content and examples.

## Scope boundaries

This repository is not a complete backup or automatic mirror of Brian's installed
skills. A skill belongs here when Brian selects it for public sharing; its local
availability alone is not a reason to include it.

## Curation standard

Favor a focused, understandable collection. Additions and revisions should help
someone use a selected skill and keep its published instructions accurate and
suitable for public access.
